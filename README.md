# The Digital Detective — Diwali Independent Learning Assignment

A hands-on system exploration project covering computer fundamentals (IPOS), command-line navigation and file operations, operating system processes and permissions, program execution (compilers vs. interpreters), number systems and text encoding, Git workflows (branches and Pull Requests), and computer networking.

## Summary of What Was Built
- **Structured Learning Repository (`digital-detective-8071`):** Organized into sequential mission folders (`mission-00-setup` through `mission-08-final-report`), each documented using a consistent 8-section technical report format and committed individually in order.
- **Terminal & OS Exploration Labs:** Practical demonstrations of file manipulation (`terminal-practice`), piping/redirection (`>` vs `>>`), process inspection (`PID`), and UNIX file permissions (`rwx`).
- **Python Programs:** Built `hello.py` (Mission 4) and an interactive CLI `number_converter.py` (Mission 5) that converts positive decimal integers into binary and hexadecimal.
- **Git Branching & Collaboration:** Created feature branch `update-about` and opened a Pull Request on GitHub (`arushvantore/digital-detective-8071`).
- **Network Diagnostics:** Executed privacy-safe connectivity (`ping`) and DNS resolution (`nslookup`) tests on `example.com`.

## How to Run `number_converter.py`
1. Ensure Python 3 is installed (`python3 --version`).
2. From the repository root folder, run:
   ```bash
   python3 mission-05-numbers-data/number_converter.py
   ```
3. Enter any positive decimal integer when prompted (for example, `13`, `25`, or `42`) to view its binary (`0b...`) and hexadecimal (`0x...`) equivalents.

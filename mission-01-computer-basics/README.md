# Mission 1 — Know your computer

## 1. Task / objective
Explain how a computer receives input, processes information, produces output, and stores results (IPOS), classify hardware and software items, and identify everyday computer-based systems.

## 2. Work completed

### Task 1.1 — Trace one activity using IPOS
**Chosen activity:** Typing and saving a short note in a text editor.

| Stage | What happens in your example? | Possible hardware / component |
| :--- | :--- | :--- |
| Input | I type characters on the keys and click save on the screen. | Keyboard, trackpad |
| Processing | The processor turns my keystrokes into digital text and prepares the file to save. | CPU, RAM |
| Output | The typed words and saved status appear on the screen. | Laptop display |
| Storage | The file is saved permanently on the internal drive so it stays after shutdown. | SSD (Solid State Drive) |

**How the activity moves through IPOS:** Keystrokes enter as raw input signals, the CPU and temporary RAM process them into readable characters shown on the display as output, and pressing save writes the file from RAM onto the permanent SSD.

## 4. My understanding
Every computer system works through the IPOS cycle by taking input, processing data in the CPU and RAM, showing output, and saving files to storage. Hardware provides the physical parts, while operating systems, apps, and utilities manage resources and help users perform tasks.
